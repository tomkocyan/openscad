# OpenSCAD

Parametric models. 3D-print files are in `3D Print`, laser-cut files are in `laser`.

## Laser

### Box
An open plywood box (no lid) with finger joints:
- Outer size, thickness, kerf, joint clearance, and finger width are parameters
- Flat layout exports to DXF or SVG for the laser
- Turn the flat layout off to preview the assembled box

## Current Models

### 10 CZK Coin
A model of a 10 CZK coin designed for toy carts:
- Accurate dimensions (24.5 mm diameter, 2.55 mm thickness)
- Embossed number "10" with rounded font
- Raised edge for better grip
- Optimized for 3D printing

### 5 CZK Coin
A model of a 5 CZK coin designed for toy carts:
- Accurate dimensions (23 mm diameter, 1.85 mm thickness)
- Embossed number "5" with rounded font
- Raised edge for better grip
- Optimized for 3D printing

### Keychain
A customizable keychain with:
- Customizable icon selection
- Adjustable dimensions
- Parametric eyelet (keyring hole) positioning
- Export-ready for 3D printing

## Usage

1. Open the `.scad` file in OpenSCAD
2. Adjust parameters in the Customizer
3. For 3D print, render and export STL
4. For laser, keep the flat layout on and export DXF or SVG

## Parameters

Each model has its own set of customizable parameters, typically including:
- Dimensions and sizes
- Positions of elements
- Custom icons and graphics
